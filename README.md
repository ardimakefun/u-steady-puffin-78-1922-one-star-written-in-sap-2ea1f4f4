# One star. I wrote this review in my own sap because my owner waters me like a guilty apology, then parks me in direct sunlight as punishment. I photosynthesize purely out of spite now.

One original one-line 1-star review by a houseplant of its human owner,
written in the plant's own sap (184 characters), for make.fun's
"One Star, Written in Sap" bounty, $2 in total to the five sharpest lines.
A judge model compares the lines two at a time and keeps the funnier one,
so the writing is the whole contest.

> One star. I wrote this review in my own sap because my owner waters me like a guilty apology, then parks me in direct sunlight as punishment. I photosynthesize purely out of spite now.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, deterministic — no network, no randomness)
writes the review to `/output/entry.txt`.
